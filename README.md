# AI-Based Internship Recommendation System 🚀

An AI-powered internship recommendation system that matches applicants with relevant internships using semantic similarity and NLP techniques. The project uses Sentence Transformers embeddings and cosine similarity to recommend internships based on applicant skills and internship descriptions.

---

## 📌 Features

- AI-based internship recommendation system
- Semantic similarity matching using Sentence Transformers
- Internship and applicant profile comparison
- Flask-based backend API
- Data preprocessing and text cleaning
- Cosine similarity recommendation pipeline

---

## 🛠️ Tech Stack

- Python
- Flask
- Pandas
- NumPy
- Sentence Transformers
- Scikit-learn

---

## ⚙️ How It Works

1. Applicant skills and internship descriptions are processed  
2. Text data is cleaned and preprocessed  
3. Sentence embeddings are generated using `all-MiniLM-L6-v2`  
4. Cosine similarity is calculated between profiles  
5. Most relevant internships are recommended
